# temperature-sensor-acquisition-system
Reconfigurable Temperature Sensor Acquisition System

Bachelor thesis project focused on the development of a data acquisition system for temperature sensors.

Sensors used:
- NTC thermistor
- Pt1000 RTD

Technologies:
- Arduino
- LabVIEW
- NI myDAQ
- Analog signal conditioning

Main features:
- sensor switching
- temperature conversion
- real-time monitoring
- min/max/average tracking

 Note: An Arduino-based implementation for sensor acquisition was also explored during the development of the project. Due to time constraints, the final implementation focused primarily on the LabVIEW-based acquisition system.
Note:The LabVIEW Virtual Instrument used in this project was originally provided as a template during the course and later modified as part of the thesis work.
